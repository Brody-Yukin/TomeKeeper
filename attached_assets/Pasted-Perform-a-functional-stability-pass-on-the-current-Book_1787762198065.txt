Functional requirements:

1. Fix library state and persistence.

* Replace state mutations that close over the current `books` array with functional `setBooks(current => ...)` updates.
* Load AsyncStorage safely with `try/catch`.
* Do not overwrite storage with an empty library before the initial storage load finishes.
* Persist library changes through one reliable persistence path.
* Log storage failures safely without crashing the application.
* Preserve the existing AsyncStorage key and all existing saved libraries.
* Normalize ISBNs by removing spaces and hyphens and uppercasing `X`.
* Use normalized ISBNs for duplicate detection.
* Prevent duplicates when the same ISBN is entered with different formatting.
* Clamp page progress between zero and the book’s page count.
* Clamp ratings between one and five.
* Clear `dateFinished` if a finished book is changed back to Reading or To Read.

2. Fix “Clear All Books.”

* Add one atomic `clearBooks()` context operation.
* Update the Stats & Settings screen to use it.
* Do not loop through the library calling `removeBook()` repeatedly.
* Confirm that clearing the library removes every book from state and AsyncStorage.

3. Make ISBN catalog lookup resilient.

* Keep `GET /api/books/isbn/:isbn` server-side.
* Validate ISBN-10 and ISBN-13 checksums.
* Query Google Books using the server-only `GOOGLE_BOOKS_API_KEY`.
* Never expose that key through an `EXPO_PUBLIC_*` variable.
* Add Open Library as a fallback when Google:

  * returns no matching item,
  * returns a quota/rate-limit error,
  * is temporarily unreachable.
* Preserve the originally requested ISBN when the fallback record does not provide a better edition-specific ISBN.
* Return:

  * `400` for an invalid ISBN,
  * `404` only after all available catalogs successfully return no match,
  * `502` when catalogs fail and no fallback result can be returned.

4. Move title/author edition searches to the server.

* Add `GET /api/books/search`.
* Accept a required title and optional author and publisher.
* Validate and limit query-string lengths.
* Search Google Books using the server-only API key.
* Retry without publisher when publisher-specific searching returns no results.
* Add Open Library title/author search as a fallback.
* Return multiple candidate editions.
* Deduplicate candidates by ISBN.
* Keep the existing client-side ranking using title, author, publisher, and edition text.
* Update `artifacts/bookshelf/utils/googleBooks.ts` so it no longer calls `googleapis.com` directly.

5. Complete the existing manual-entry fallback.

* If an ISBN is entered, validate its checksum.

* Prefill recognized title, authors, publisher, and possible ISBN after successful cover recognition with no catalog match.
